二、cp_final_ex 專案（try2）

接著回到上一層目錄，將第二個遊戲專案 clone 成 try2。

cd .. git clone https://github.com/mdecycu/cp_final_ex.git try2 cd try2

執行專案：

python app.py

啟動後，可以正常進入首頁，並且測試了註冊、登入與遊戲頁面等功能，從伺服器輸出的紀錄中可看到 POST 與 GET 的狀態碼，顯示整體流程運作正常。

在後續修改程式時，出現語法錯誤：

SyntaxError: invalid syntax. Perhaps you forgot a comma?

檢查後發現錯誤程式碼如下：

app.run(debug=True port= 5123)

這行程式碼少了一個逗號，修正後改為：

app.run(debug=True, port=5123)

再次執行後，Flask 成功在新的埠號 5123 啟動，這次經驗讓我了解到 Flask 啟動參數的語法必須正確，否則會導致程式無法執行。
